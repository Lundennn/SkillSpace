# SkillSpace — Frontend

Клиентская часть образовательной платформы **«СкиллСпейс»**. Проект построен на масштабируемой компонентной архитектуре (собственный UI Kit + переиспользуемые шаблоны страниц) с использованием семантической и адаптивной вёрстки по дизайн-макетам.

## Стек технологий

* **Фреймворк:** React.js (функциональные компоненты, хуки `useState`)
* **Маршрутизация:** React Router (`BrowserRouter` для обычной сборки, `HashRouter` для `npm run deploy` на GitHub Pages). Локальный лендинг открывается на `http://localhost:5173/`. Для обычной сборки настройте сервер на выдачу `index.html` при прямом открытии маршрутов приложения.
* **Сборщик:** Vite
* **Разметка и стили:** Семантический HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`), CSS3 (Grid, Flexbox, CSS Custom Properties, медиазапросы)
* **Деплой:** `gh-pages`

## Реализованный функционал и маршруты

Проект включает полноценный флоу аутентификации:
* `#/register` — Регистрация нового профиля.
* `#/email-confirm` — Ввод 6-значного кода из письма (состояния пустой и заполненной формы).
* `#/email-confirmed` — Успешное подтверждение почты.
* `#/2fa` — Настройка двухэтапной аутентификации (QR-код и секретный ключ).
* `#/login` — Вход в личный кабинет.

## Архитектура и UI Kit

* **Шаблоны каркаса (`src/components/layout/`):**
  * `AuthLayout` — двухколоночный макет с шапкой, промо-блоком (векторный график) и слотом под формы. Текст пропорционально адаптирован под разные экраны.
  * `CenteredLayout` — макет с центрированной карточкой и фоновым свечением для страниц подтверждения и 2FA.
* **Модульный UI Kit (`src/components/ui/`):**
  * `Input` — текстовые поля с переключателем видимости пароля.
  * `CodeInput` — специализированное поле для ввода одноразовых 6-значных кодов с разрядкой.
  * `Button` — универсальные кнопки с вариантами оформления (`accent`, `primary`, `social`) и стилями неактивного состояния (`disabled`).
  * `Checkbox` — кастомный стилизованный чекбокс.
  * `Icon` — единый каталог контурных SVG-иконок (`16×16`, `stroke: 1.4`, `round`).

## Дизайн-система и CSS-токены

Все глобальные переменные вынесены в `:root` внутри `src/index.css`:

* **Типографика:**
  * Заголовки и метки (`--font-heading`) — `JetBrains Mono` (500, 600, 700)
  * Основной текст и поля форм (`--font-body`) — `Inter` (400, 500, 600)
* **Цветовая палитра:**
  * `--color-bg`: `#313642` — основной фон
  * `--color-bg-deep`: `#272b35` — глубокий фон (шапка и секции карточек)
  * `--color-surface`: `#404655` — поверхность полей ввода
  * `--color-surface-alt`: `#4a5060` — границы и разделители
  * `--color-primary`: `#5CBBF1` — ссылки и интерактивные элементы
  * `--color-accent`: `#CDFF08` — акцентный цвет (кнопки CTA, иконки)
  * `--color-text`: `#ffffff` — основной текст
  * `--color-text-secondary`: `#adb5c4` — вторичный текст
  * `--color-text-muted`: `#6b7587` — приглушённый текст (подписи, метки)
  * `--color-error`: `#f04444` — ошибки и деструктивные действия

## Локальная проверка авторизации

Нужны запущенный Docker Desktop и два соседних репозитория в GPO. В первом терминале:

```sh
cd /Users/markld/my/GPO/auth-service
docker compose --profile email up --build -d --wait
curl --fail http://localhost:8080/health/ready
```

Во втором терминале:

```sh
cd /Users/markld/my/GPO/SkillSpace
npm ci
npm run dev
```

Откройте [SkillSpace](http://localhost:5173/) и [Mailpit](http://localhost:8025/). Vite перенаправляет запросы `/api` в локальный auth-service на порт 8080.

1. Нажмите «Регистрация», введите новый тестовый email, пароль из 12–128 символов и отметьте согласие.
2. Найдите письмо по адресу получателя в Mailpit и введите шестизначный код. На экране «Почта подтверждена» нажмите «Перейти ко входу».
3. Введите те же email и пароль. Если с отправки первого письма прошло меньше минуты, дождитесь окончания паузы, которую показывает форма, и повторите вход. Найдите новое письмо в Mailpit и введите код входа. Откроется личный кабинет, который проверяет сессию через API.
4. Нажмите «Выйти». Приложение отзывает сессию и возвращает на главную. Прямое открытие `/account` после выхода ведёт на страницу входа.

Токен хранится в памяти приложения. После полной перезагрузки страницы потребуется войти снова. Для запроса нового кода нужно повторно отправить исходную форму. Для запуска вне Vite настройте на сервере проксирование `/api` к auth-service.
